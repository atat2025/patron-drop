Sei PATカーブを止める（オーナー用）

このページはオーナーのウォレットで署名するための非公開ページです。検索にも出ません。開くたびに最新の残高を読み、送る前に事前チェックをします。

読み込み中…

第1段階：購入を止めて、在庫と手数料を戻す

これで誰も新しく買えなくなります。残っているPATと、すでに貯まっている手数料のSEIがオーナーのウォレットに戻ります。すでに売った分のSEI（買い戻し用）は、この段階ではまだプールに残ります。

1. 購入を停止する

呼び出す関数: setPaused(true)。売却（売り戻し）は開いたままです。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B（PatCurve）、送金額 0 SEI。これ以外の宛先や金額なら、確認を押さないでください。

2. 残っているPATを戻す

呼び出す関数: withdrawInventory(オーナー, 在庫すべて)。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B、送金額 0 SEI。

3. 手数料のSEIを戻す

呼び出す関数: withdrawFees(オーナー)。買い戻し用のSEIは引き出せません。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B、送金額 0 SEI。

第2段階（任意）：残りのSEIを回収する

コントラクトには、買い戻し用のSEI（いま約221 SEI）を直接引き出す関数はありません。回収するには、オーナーが「すでに売れた枚数」と同じPATをカーブに売り戻す必要があります。

注意: これを行うと、カーブからPATを買った人がいた場合、その人はもう売り戻せなくなります（売却も止まります）。第1段階だけでも購入は止まります。残りのSEIを回収して、完全に空にしたいときだけ進めてください。
4. 売り戻しの許可

PATコントラクトで approve(カーブ, 売れた枚数) をします。

準備中…

MetaMask に出る内容: 宛先 0x3d9C71…4e95（SeiのPAT）、送金額 0 SEI。

5. PATを売り戻してSEIを受け取る

呼び出す関数: sell(売れた枚数, …)。手数料を除いたSEIがオーナーに入ります。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B、送金額 0 SEI。

6. 売り戻したPATを再び引き出す

売り戻すとPATがカーブに戻るので、もう一度 withdrawInventory します。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B、送金額 0 SEI。

7. 売り戻しの手数料を引き出す

呼び出す関数: withdrawFees(オーナー)。

準備中…

MetaMask に出る内容: 宛先 0x88b1de…C99B、送金額 0 SEI。

ガス代の目安は、全部で約 0.02 SEI です。オーナーのSEI残高がそれより少ない場合は、先に少しSEIを入れてください。署名はすべて久積様ご自身のウォレットで行います。
